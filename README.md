# Hospital Management System

A simple console-based **Hospital Management System** developed in C++ as an individual training project.

## Features

* Patient Management
* Doctor Management
* Appointment Management
* Medical Records
* Pharmacy Management
* Billing
* Linux System Programming
* Process & Thread Management
* IPC
* Linux Device Driver Demonstration
* Hardware/Software Interaction

## Technologies

* C++
* Linux
* GCC/G++
* Git & GitHub
* UML
* Linux System Programming

## Project Structure

```text
Hospital-Management-System/
├── src/
└── README.md
```

## Current Status

The initial C++ console application is working with core hospital management features.

Future stages will add Linux system programming, processes, threads, IPC, and a small simulated Linux device driver.

## Build

```bash
g++ -std=c++17 -Wall -Wextra src/main.cpp -o hospital
```

Run on Linux:

```bash
./hospital
```

Run on Windows PowerShell:

```powershell
.\hospital.exe
```

## Scope

This is an **educational project** demonstrating C++, Linux, system programming, computer architecture, hardware/software concepts, device drivers, testing, and version control.

No database is used.
